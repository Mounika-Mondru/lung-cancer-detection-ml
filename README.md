# 🫁 Lung Cancer Detection Using Machine Learning

## 📌 Project Overview

Lung Cancer Detection Using Machine Learning is a predictive system developed to identify the likelihood of lung cancer based on patient health details and symptoms.

This project uses machine learning algorithms to analyze patient information and predict whether lung cancer is detected or not. A user-friendly web application is developed using Streamlit to make predictions through an interactive interface.

## 🎯 Objectives

- To analyze patient health information related to lung cancer.
- To perform data preprocessing and exploratory data analysis.
- To train and evaluate machine learning classification models.
- To develop an interactive prediction application using Streamlit.
- To demonstrate how machine learning can be applied to healthcare data.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning Models:** Logistic Regression, Random Forest, XGBoost
- **Frontend:** Streamlit
- **Development Environment:** Jupyter Notebook, Anaconda

## 📊 Dataset

The project uses the **Survey Lung Cancer Dataset**.

The dataset contains patient information and health-related attributes, including:

- Gender
- Age
- Smoking
- Yellow Fingers
- Anxiety
- Peer Pressure
- Chronic Disease
- Fatigue
- Allergy
- Wheezing
- Alcohol Consuming
- Coughing
- Shortness of Breath
- Swallowing Difficulty
- Chest Pain
- Lung Cancer (Target)

## ⚙️ Machine Learning Workflow

1. Import the required Python libraries.
2. Load the lung cancer dataset.
3. Perform data preprocessing.
4. Encode categorical variables.
5. Perform exploratory data analysis.
6. Split the dataset into training and testing sets.
7. Train classification models.
8. Evaluate model performance.
9. Save the trained Logistic Regression model using Pickle.
10. Integrate the saved model with the Streamlit application.

## 🤖 Machine Learning Algorithms

The following classification algorithms are explored in this project:

- Logistic Regression
- Random Forest Classifier
- XGBoost Classifier

The saved Logistic Regression model is used in the Streamlit application for prediction.

## 💻 Streamlit Web Application

The project includes an interactive web application developed using Streamlit.

### Features

- User-friendly interface.
- Patient information input fields.
- Gender and age selection.
- Health-related symptom inputs.
- Lung cancer prediction button.
- Prediction result display.

### Prediction Results

The application displays one of the following results:

- Lung Cancer Detected
- No Lung Cancer Detected

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/lung-cancer-detection-ml.git
```

### Step 2: Navigate to the Project Folder

```bash
cd lung-cancer-detection-ml
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Run the Streamlit Application

```bash
streamlit run app.py
```

### Step 5: Open the Application

Open the following URL in your browser:

```text
http://localhost:8501
```
